Exercise 2: Public & Private Keys (Asymmetric Cryptography)

The Situation:

You are acting as a verification node on a blockchain network. Four different users are trying to send transactions across the network.

To authorize a transaction, a sender must provide two things:

  1. Their Public Key (their known network address).
  2. Their Private Key Signature (their secret digital stamp).

Below the main network log, you have been provided with a secure Key Registry—a database that shows which Private Key is mathematically paired to which Public Key.

Your Objective:

  1. Automate the Verification: Simulate the spreadsheet formula by entering the submitted private keys. The system will automatically check if it matches the registry.
  2. Diagnose the Network Failures: Only one of these transactions is completely valid. The other three contain critical security errors. Once the status flags the errors, look closely at the data submitted in that row. Figure out exactly what the sender did wrong, and type your explanation in the Network Analysis column.

💡 Formula Hint (For a Spreadsheet):

To automate this in a real Google Sheet, you would use a VLOOKUP function in the Status column. Your syntax would look something like this:

=IF(VLOOKUP([Cell with Public Key], [Highlight Key Registry Range], 2, FALSE) = [Cell with Submitted Private Key], "Valid", "Forged/Error")
